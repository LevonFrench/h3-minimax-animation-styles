# Research — Value-Graph Easing Demonstration

## Actionable vocabulary

- A value graph shows position over time: near-horizontal tangents at departure/arrival create soft ease; a position overshoot crosses the target value and returns.
- Contrast the prior speed-graph reading by making the S-shaped value curve visible as a thin overlay, while keeping the moving circle itself primary.
- Use one clean Bezier easing profile and one small corrective settle; avoid repeated springiness.
- Exact geometric alignment and a locked camera make curve-to-motion correspondence legible.
