# Research — Vector Shape-Layer Construction Reveal

## Actionable vocabulary

- Shape layers are synthetic vector objects built from paths, strokes, fills, groups, and animatable path operations. Parametric circles retain exact geometry.
- A clean overshoot uses one scale peak, one undershoot, then settle; opposing concentric rotations should remain centered and mathematically aligned.
- Guide lines and anchor markers can briefly reveal construction, but they should remain thin, unlabeled, and disappear before the solid circle returns.
- Controlled motion blur belongs only on the rotating strokes; flat color and crisp edges define the finish.
